# StringUtil

**문자열**

## 메서드

| 메서드 | 설명 |
|---|---|
| `isEmpty(strValue)` | None 또는 "" |
| `nvl(strValue, strDefault)` | 비었으면 기본값 |
| `equalsIgnoreCase(a, b)` | 대소문자 무시 비교 (둘 다 None이면 True) |
| `isPositiveInteger(strValue)` | 1 이상의 정수 문자열인지 |
